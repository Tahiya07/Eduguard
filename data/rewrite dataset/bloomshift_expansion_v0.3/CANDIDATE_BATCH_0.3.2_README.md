# BloomShift expansion candidate batch 0.3.2

This batch adds 27 manually drafted candidate rewrites based on the source questions recorded in `source_candidates_for_rewrite.csv`.

## Coverage

- 27 candidate records.
- 12 Create-level candidates, addressing the Create-level gap in batch 0.3.1.
- The remaining candidates cover Remember, Understand, Apply, Analyze, and Evaluate.
- Each record includes the original source question, source group ID, target Bloom level, selected opening verb, a level-specific action-verb bank, preserved elements, semantic risks, and review status.

## Create-level handling

The 12 Create-level examples use source questions already labeled Create in the candidate pool. They are not generated by simply replacing an opening verb. They ask for a concrete product or plan where the source supports one—for example, an SEM plan, keyword-research workflow, storyboard, multimedia presentation, coupon concept, architecture diagram, circuit sketch, or new sport.

Some source prompts are underspecified or refer to missing context. Their risks are explicitly recorded; these examples must not be treated as automatically valid meaning-preserving rewrites. In particular, added planning fields or output details require human judgment about whether they are acceptable elaborations.

## Validation status — not training-ready

- Human validation: pending for every record.
- Training eligibility: false for every record.
- Feasibility and semantic risks are preliminary author annotations, not validation results.
- The source pool contains 2,007 candidate questions, but this batch does not establish that every selected source is globally unused across all historical datasets.
- The batch is an addition, not a replacement for the existing train/validation/test sets or the earlier candidate batch.
- Before training, inspect semantic preservation, target Bloom alignment, action-verb appropriateness, context completeness, duplicates, and source-group leakage. Keep all rewrites from one source group in the same split.

Action-verb diversity is an audit aid only: a verb by itself does not prove cognitive-level alignment.
